# Capture (Obsidian plugin) — BRAT distribution

Built from the [`obsidian_workspace.obs`](https://github.com/SilentNinja06/obsidian_workspace.obs) monorepo (`plugins/capture`).

Install with **BRAT**: Add Beta Plugin → `SilentNinja06/capture_obs`.

Each push of a new build cuts a GitHub Release named by the manifest version, which BRAT installs and auto-updates from.
